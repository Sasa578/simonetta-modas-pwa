# ARQUITECTURA EXIGIDA
1. **Base de Datos:** PostgreSQL. OBLIGATORIO respetar la Tercera Forma Normal (3FN). Usa llaves foráneas estrictas. Las contraseñas deben usar Bcrypt.
2. **Backend:** Node.js + Express. Patrón estricto MVC (Modelo, Vista, Controlador separados). Rutas protegidas con JWT.
3. **Frontend:** React + Vite (PWA). Diseño Mobile-First. Botones táctiles grandes (44x44px). Estilo elegante, minimalista y orientado a la alta costura. Sin plantillas genéricas.
